Privacy policy

Last updated: 28 October 2026

Poster Studio is a private desktop app used only by its owner on their own computer.

What it accesses

With the user's permission, Poster Studio uses the Google Drive permission drive.file. This lets it see and change only the files and folders that Poster Studio itself creates, or that the user explicitly chooses for it in Google's own folder picker. It cannot see any other files on the user's Google Drive.

What it does with it

It uploads the poster and mockup files it makes and reads back their links. The sign-in token is kept only on the user's own computer.

What it never does

It does not sell, share or send any Google user data to anyone. It has no advertising and no tracking. No data is kept on any server.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
